# MWD–地震物理约束岩石强度融合：计算方法说明

Computational note on physics-constrained fusion of MWD and seismic rock strength

**摘要。** 本文给出本仓库三维岩石强度场 $S(x,y,z)$ 的完整计算方案：从随钻参数与叠后地震出发，经可推导的正反演与克里金，再到外漂移克里金融合。现场能直接测到的只有两类不对等观测——沿钻孔的力学硬数据，以及全区连续、但只与强度间接相关的波阻抗。方案把随钻测量（MWD）反演成带方差的主变量场 $S_M$，把地震反演成波阻抗并在共定位孔点上标定得到次变量 $S_Z$，再用外漂移克里金（KED）把 $S_Z$ 当作漂移、孔点 UCS 当作硬数据；单口井改走 Doyen 共定位更新以免过拟合扩散。插值核、变差函数与文献推导见 [插值方法.md](插值方法.md)。定量结论来自固定种子的共定位合成矿山（`seed = 42`，14 口梅花孔，网格 $25 \times 40 \times 40$，块段 $50 \times 80 \times 40~\mathrm{m}$，默认工作面 $20 \times 50~\mathrm{m}$）。该工作面上融合 $R^2 = 0.848$、RMSE $= 5.17~\mathrm{MPa}$，低于仅钻孔（$8.37$）、仅波阻抗（$8.02$）与简单平均（$7.14$）。孔轨迹上融合与仅钻孔同为 $2.41~\mathrm{MPa}$。图件保存在 [`images/`](images/)。

**关键词：** 随钻测量；波阻抗反演；外漂移克里金；物理引导高斯过程；岩石单轴抗压强度

## 1. 引言

露天矿爆破设计与岩体分区需要连续的三维强度场，而现场能直接测到的只有两类不对等的观测（表 1）。MWD 与岩心给出钻速、转速、扭矩、轴压以及孔内 UCS，空间上是横向极稀的一维线，但与目标量接近。三维地震给出叠后振幅，空间上全区连续，但必须经过波阻抗 $\mathrm{AI}=\rho V_p$ 才与强度间接相关。

**表 1 | 两类观测。** UCS 为目标量（单轴抗压强度）。

| 源 | 测到什么 | 空间覆盖 | 与 UCS 的关系 |
| --- | --- | --- | --- |
| MWD + 岩心 | 钻速 $V$、转速 $N$、扭矩 $M$、轴压 $F$，以及孔内 UCS | 沿钻孔的一维线，横向极稀 | 力学响应，接近目标量 |
| 三维地震 | 叠后振幅 | 全区连续 | 经波阻抗 $\mathrm{AI}=\rho V_p$ 间接相关 |

仅用钻孔把 UCS 插值到三维，即使缩到 $20 \times 50~\mathrm{m}$ 的工作面、14 口孔按梅花均匀布置在内部，相邻孔距仍约一个工作面尺度。克里金在孔旁忠实，孔间变光滑：硬矿体轮廓发糊，断裂和蚀变晕对不上。这不是选错了插值核，而是观测几何不够 [1]–[4]。

地震波阻抗是全空间场，能看见这些结构，但它不是强度。本方案的核心不是“换一个更好的插值核”，而是储层建模里井加地震的标准做法 [5], [6]：把 MWD 反演成带方差的强度场 $S_M,\sigma_M^2$（孔旁准、远处不准）作为主变量的克里金；把地震反演成波阻抗，再在共定位点上标定 $\mathrm{UCS}=f(\mathrm{AI})$，得到全区次变量 $S_Z$；用外漂移克里金把 $S_Z$ 当作漂移、孔点 UCS 当作硬数据。残差变程取孔距，硬矿体峰值不被共定位相关系数 $\rho$ 打折；单口井才走 Doyen 更新。

因此，融合的收益来自把连续波阻抗当作次变量，而不是当作另一张可以和钻孔对半平均的强度图。井是硬数据，地震是约束。符号约定与 [插值方法.md](插值方法.md) 第 2 节一致。

## 2. 相关工作

区域化变量理论把空间估计写成变差函数约束的线性无偏组合 [1], [2]。矿业与石油实践中，井稀而准、地震密而不准是同一类数据配置。Xu、Tran、Srivastava 与 Journel 比较了外漂移克里金（井为硬数据，地震为漂移）与共定位协克里金 [5]。Doyen、den Boer 与 Pillet 把共定位协克里金写成对井克里金的贝叶斯更新，并用于 Ekofisk 孔隙度填图 [6]。土壤学把线性协变量加残差克里金称作回归克里金，并证明它与 KED 在线性漂移下等价 [7], [8]。多元地统计的系统表述见 Wackernagel [9] 与 Chilès、Delfiner [10]。

本仓库在两口井及以上采用 KED 而不是 Doyen 更新，因为后者在远处按 $\rho$ 把次变量异常往均值缩。本基准 $\rho\approx 0.76$，硬矿体在 $S_Z$ 上的峰值会被压到约四分之三。KED 没有这一项：漂移系数乘在整张 $S_Z$ 上，残差只在孔距尺度上插值。

随钻方面，Teale 把破碎岩石所做的功收成比能，并指出它与强度单调相关 [11]。叠后波阻抗反演是带限反问题：缺低频则绝对阻抗漂，缺高频则界面发糊。稳定化采用 Tikhonov 正则 [12] 与平滑低频背景，这是模型基反演的标准写法。零相位 Ricker 子波提供褶积核 [13]。

公开数据中不存在共定位的 `MWD + UCS + 三维地震 + AI`。因此本仓库用合成矿山提供可计算的体积误差，而不是训练端到端网络去同时拟合两路——那种网络在没有成对真值时无法验证。

## 3. 方法

### 3.1 总体流程

两路独立反演，只在共定位孔点上交换信息（MWD 训练样本、AI–UCS 标定样本）。实现入口：`fusion.pipeline.run_fusion_pipeline`。

```
真值世界 (UCS_true, AI_true, 共定位 MWD)
        |                              |
   MWD 分支                       地震分支
   V, N, M, F → 比能特征 → PG-GPR   AI → 反射系数 → 合成地震
   → 孔点 UCS 与 σ                   → Tikhonov 反演 → AI_inv
   → 以深度为趋势的回归克里金         → 孔点 GP 标定 UCS = f(AI)
   → S_M, var_M                      → S_Z, var_Z
        └─ 外漂移克里金（漂移 = 深度 + S_Z；单井 Doyen）─┘
                          |
                    S_F, var_F  与 UCS_true 对比
```

### 3.2 合成矿山真值

公开数据天然是拆开的：有 MWD 无地震，或有地震无 MWD。`datasets.generate_mine` 因此构造同一坐标系下的真值，使融合误差可计算。

潜变量“岩体胜任度” $c(x,y,z)$ 同时驱动 UCS 与 AI，二者相关但不是恒等：UCS 另加风化 / 蚀变力学残差（波阻抗看不见），AI 另加独立声学纹理。若不做这个拆分，$\mathrm{corr}(\mathrm{AI},\mathrm{UCS})$ 会冲到 $0.98$，平面图上钻孔分支看起来像多余。UCS 与 AI 的仿射标定：

```math
\mathrm{UCS}=20+150\,c_{\mathrm{UCS}} \quad(\mathrm{MPa}),
\qquad
\mathrm{AI}=\bigl(4+7\,c_{\mathrm{AI}}\bigr)\times 10^{6}
\quad\bigl(\mathrm{kg}\,(\mathrm{m}^{2}\mathrm{s})^{-1}\bigr).
\qquad (1)
```

其中 $c_{\mathrm{UCS}}\approx 0.52 c - 0.50 c_{\mathrm{mech}}$，$c_{\mathrm{AI}}\approx 0.40 c + 0.60 \tau$，$\tau$ 为独立平滑随机场。本基准 $\mathrm{corr}(\mathrm{AI},\mathrm{UCS})\approx 0.76$。

MWD 由 UCS 经单调物理关系加噪声生成，例如钻速随强度指数衰减、轴压 / 扭矩随强度上升。因此 `MWD → UCS` 可学但有噪声。

14 口孔按爆破常用的梅花 / 三角网格近似均匀铺在默认 $20 \times 50~\mathrm{m}$ 工作面内部（邻行错半个孔距，中列补两个孔，格子相对工作面内缩约三分之一孔距，不贴边）。全块仍是 $50 \times 80~\mathrm{m}$，便于把工作面平移到别处。$1\to N$ 实验的嵌套前缀按最远点排序，稀疏子集同样铺开，而不是挤在一角。孔内每个深度节点都有样本。

![图 1. 梅花布孔](images/hole_layout.png)

**图 1 | 梅花布孔。** 合成块段平面 $50 \times 80~\mathrm{m}$。14 口孔全部落在中心 $20 \times 50~\mathrm{m}$ 工作面内。色点为孔口平面位置。`seed = 42`。对应的可平移窗口见 [插值方法.md](插值方法.md) 图 1b。

默认模型：$X\in[0,50]~\mathrm{m}$，$Y\in[0,80]~\mathrm{m}$，标高 $0\to -40~\mathrm{m}$，约 10 个台阶。下文所有图与表均来自该模型、`seed = 42`、14 口孔，评价指标限制在默认工作面体积上。

克里金代价随孔点数与网格体积上升。合成全块保持网格 $25 \times 40 \times 40$。前端与出版图默认只显示该工作面，并提供 $X$、$Y$ 原点滑条在全块上平移窗口。这是可视化截取，不是重新插值：三维场仍在全块上一次算完。

### 3.3 MWD 分支：孔点预测加三维克里金

原始通道：钻速 $V$、转速 $N$、扭矩 $M$、轴压 $F$。报告约定的比能（`mwd.features.specific_energy`）为 [11]

```math
\mathrm{SE}' \;=\; F + \frac{2\pi N M}{V}
\qquad (2)
```

（分母加 $10^{-9}$ 防止零钻速）。再拼无量纲比，得到 8 维特征

```math
\mathbf{x}=\bigl(V,\,N,\,M,\,F,\,\mathrm{SE}',\,M/F,\,V/N,\,V/F\bigr).
\qquad (3)
```

$\mathrm{SE}'$ 把破碎岩石所做的功收成一个与强度单调相关的物理量，后面的高斯过程用它做均值函数，而不是让核函数凭空学这个趋势。

纯数据 GPR 在样本外会漂。PG-GPR（`mwd.ucs_model.PhysicsGuidedGPR`）把比能线性趋势当作 GP 均值函数，GP 只拟合残差：

```math
\mathrm{UCS}(\mathbf{x})
=\underbrace{\beta_0+\beta_1\,\mathrm{SE}'(\mathbf{x})}_{m(\mathbf{x})}
+ f(\mathbf{x})+\varepsilon,
\qquad (4)
```

其中 $f\sim\mathcal{GP}(0,k)$，核为

```math
k(\mathbf{x},\mathbf{x}')
= \sigma_f^{2} \exp\Bigl(-\frac{\|\mathbf{x}-\mathbf{x}'\|^{2}}{2\ell^{2}}\Bigr)
+ \sigma_n^{2}\,\delta_{\mathbf{x}\mathbf{x}'}.
\qquad (5)
```

训练：先对 $\mathrm{SE}'$ 做线性回归得 $\hat{\beta}$，再对残差 $y_i-m(\mathbf{x}_i)$ 拟合 GP（特征经标准化）。预测

```math
\hat{\mu}_{\mathrm{hole}}(\mathbf{x})=m(\mathbf{x})+\mathbb{E}[f\mid \mathcal{D}](\mathbf{x}),
\qquad
\hat{\sigma}_{\mathrm{hole}}(\mathbf{x})=\sqrt{\mathrm{Var}[f\mid \mathcal{D}](\mathbf{x})}.
\qquad (6)
```

样本稀疏时预测退回比能基线，而不是漂到无物理意义的值；$\hat{\sigma}_{\mathrm{hole}}$ 进入下一步的融合方差。

孔点预测仍是一维线。空间化采用回归克里金（`geostats.regression_kriging_3d`）：深度作为协变量，吸收台阶 / 埋深趋势，残差再做普通克里金 [7], [8]。记孔点位置 $\mathbf{u}_i=(x_i,y_i,z_i)$，观测 $z_i=\hat{\mu}_{\mathrm{hole}}(\mathbf{x}_i)$。趋势

```math
m_{\mathrm{RK}}(\mathbf{u})=\alpha_0+\alpha_1 z
\qquad (7)
```

由孔点最小二乘估计。残差 $r_i=z_i-m_{\mathrm{RK}}(\mathbf{u}_i)$ 用三维普通克里金插值。普通克里金是无偏线性估计

```math
\hat{r}(\mathbf{u}_0)=\sum_{i=1}^{n}\lambda_i r_i,
\qquad
\sum_{i=1}^{n}\lambda_i=1,
\qquad (8)
```

权重由球状变差函数方程组给出。设 $\gamma(h)$ 为变差函数，$C(h)=C(0)-\gamma(h)$ 为协方差，则

```math
\begin{pmatrix}
C(\mathbf{u}_i-\mathbf{u}_j) & \mathbf{1} \\
\mathbf{1}^{\top} & 0
\end{pmatrix}
\begin{pmatrix}
\boldsymbol{\lambda} \\ \mu
\end{pmatrix}
=
\begin{pmatrix}
C(\mathbf{u}_i-\mathbf{u}_0) \\ 1
\end{pmatrix}.
\qquad (9)
```

克里金方差（残差场，代码忽略趋势系数的不确定度）

```math
\sigma^{2}_{\mathrm{OK}}(\mathbf{u}_0)
= C(0) - \boldsymbol{\lambda}^{\top} \mathbf{c}(\mathbf{u}_0) - \mu.
\qquad (10)
```

最终 MWD 场与方差：

```math
S_M(\mathbf{u})=m_{\mathrm{RK}}(\mathbf{u})+\hat{r}(\mathbf{u}),
\qquad
\sigma_M^{2}(\mathbf{u})=\sigma^{2}_{\mathrm{OK}}(\mathbf{u})+\overline{\hat{\sigma}_{\mathrm{hole}}^{2}}.
\qquad (11)
```

第二项把 PG-GPR 的点预测噪声均匀加到克里金方差上，避免把孔点 UCS 当成无误差真值。方程组与球状模型的展开见 [插值方法.md](插值方法.md) 第 3.1–3.3 节。

单口铅垂孔没有横向滞后，三维变差函数无法从数据里估出来。此时实现回退到“以样本方差为基台、以模型对角线一半为变程”的球状模型：离孔后估计退回深度趋势，方差升高。这正是“只有一口井”时插值应有的行为。

克里金是最优线性插值，不是错误的算法。它不准，是因为观测的几何不够。14 口孔按梅花铺在默认工作面内部；胜任度场仍含有矿体 / 软弱带尺度的横向结构。无横向样品时，残差克里金的最优解就是回到均值，于是一口井时 $S_M$ 几乎是平面常数；孔变密后能勾出硬矿体轮廓，但孔间仍然过平滑。$\sigma_M$ 在孔旁小、离孔大——这个方差后面会被融合用掉，而不是被丢掉。

![图 2. 仅钻孔克里金](images/mwd_only_strength.png)

**图 2 | 仅钻孔克里金插值 $S_M$。** 水平切片标高 $-20~\mathrm{m}$，默认 $20 \times 50~\mathrm{m}$ 工作面。14 口梅花孔的克里金只在靶心附近有值，孔间几乎是深度趋势，硬矿体的亮斑基本丢了。色标为 UCS（$\mathrm{MPa}$）。$n=14$，`seed = 42`。

### 3.4 地震分支：波阻抗反演加 $\mathrm{AI}\to\mathrm{UCS}$ 标定

声阻抗 $Z=\rho V_p$。层界面法向反射系数（`inversion.reflectivity`）

```math
R_i=\frac{Z_{i+1}-Z_i}{Z_{i+1}+Z_i}.
\qquad (12)
```

反变换（给定井口阻抗 $Z_0$）

```math
Z_{i+1}=Z_i\frac{1+R_i}{1-R_i}.
\qquad (13)
```

当相对扰动较小时 $R_i\approx \tfrac{1}{2} \Delta \ln Z_i$，从而反射系数对对数阻抗近似线性。反演因此在 $m=\ln Z$ 域进行。

零相位 Ricker 子波（主频 $f_0$，采样 $\Delta t$）[13]

```math
w(t)=\bigl(1-2(\pi f_0 t)^{2}\bigr)\,e^{-(\pi f_0 t)^{2}}.
\qquad (14)
```

叠后道

```math
d = W r,
\qquad
r \approx \tfrac{1}{2} D m,
\qquad
m=\ln Z,
\qquad (15)
```

其中 $W$ 为 `same` 模式褶积矩阵，$D$ 为一阶差分（末行补零以保持方阵）。复合正演算子

```math
G = W\bigl(\tfrac{1}{2} D\bigr)
\qquad (16)
```

把对数阻抗直接映射到地震道（`inversion.forward.forward_operator`）。合成记录用精确 $R_i$ 再与 $W$ 褶积，比线性化 $G$ 多保留一点非线性，作为更忠实的正演。

地震是带限的。稳定化靠两件事：平滑低频背景 $m_0=\ln Z_{\mathrm{bg}}$（井 / 层位趋势的代理，这里用对数域高斯平滑），以及二阶差分光滑项。单道问题（`inversion.model_based`）[12]

```math
\min_m \;
\|Gm-d\|_{2}^{2}
+\lambda\,\|L(m-m_0)\|_{2}^{2}
+\varepsilon\,\|m-m_0\|_{2}^{2}
\qquad (17)
```

其中 $L$ 为内点二阶差分（边界行填零）。这是严格凸二次型，法方程

```math
\bigl(G^{\top} G+\lambda L^{\top} L+\varepsilon I\bigr)(m-m_0)
= G^{\top}\bigl(d-G m_0\bigr).
\qquad (18)
```

闭式解

```math
m = m_0 + \bigl(G^{\top} G+\lambda L^{\top} L+\varepsilon I\bigr)^{-1} G^{\top} (d-G m_0),
\qquad
Z=\exp(m).
\qquad (19)
```

$G$ 只依赖子波和道长，三维体可对所有道分解一次、批量左乘。默认 $\lambda=5$，$\varepsilon=10^{-3}$，子波 31 点、$30~\mathrm{Hz}$，观测噪声为记录标准差的 $5\%$。本基准上反演阻抗相对真值 $\mathrm{AI}$ 的 $R^2=0.844$。

低频背景在现场来自井曲线沿层位插值；合成实验里用真值的重平滑代替，模拟“我们有趋势、没有高频”这一现实约束。

阻抗不是强度。只在同时有 AI 与 UCS 的孔点上学习非线性映射（`fusion.calibration.ImpedanceStrengthCalibrator`）：

```math
\mathrm{UCS}=g(\mathrm{AI})+\eta,
\qquad
g\sim\mathcal{GP}(0,k_{\mathrm{RBF}}+\text{White}).
\qquad (20)
```

AI 先标准化。预测在整个 $\mathrm{AI}_{\mathrm{inv}}$ 体上给出

```math
S_Z(\mathbf{u})=\hat{g}\bigl(\mathrm{AI}_{\mathrm{inv}}(\mathbf{u})\bigr),
\qquad
\sigma_Z(\mathbf{u})=\hat{\sigma}_g\bigl(\mathrm{AI}_{\mathrm{inv}}(\mathbf{u})\bigr).
\qquad (21)
```

标定样本随钻孔增加而变多，所以地震分支的强度场也会随孔数轻微变好——不是因为阻抗体变了（钻孔数量实验里阻抗体固定），而是 $g$ 估得更稳。一口井沿深度已有数十个 $(\mathrm{AI},\mathrm{UCS})$ 对，一维标定在 $n=1$ 时就已经可用。

### 3.5 外漂移克里金融合

井（准、稀）加地震（连续、不准）是储层建模的经典设定 [5], [6]。Doyen 更新在远处按 $\rho$ 把次变量异常往均值缩。本基准 $\rho\approx 0.76$，硬矿体在 $S_Z$ 上的峰值会被压到约四分之三，平面图上矿体发糊。KED 不这么做：漂移系数乘在整张 $S_Z$ 上（本基准约 $0.84 S_Z - 0.30 z$），残差再按孔距插值，峰值保住，孔间力学残差也不会被铺到全块。

把已经插好的 $S_M$ 和 $S_Z$ 当成独立观测做逆方差混合，假设不成立——两路共用同一批标定井。$S_F$ 按 KED 构造，孔轨迹体素再写回 PG-GPR 点估计。

主变量为孔点 UCS $\hat{\mu}_{\mathrm{hole}}$，漂移为深度与标定强度

```math
m_{\mathrm{KED}}(\mathbf{u})=\alpha_0+\alpha_1 z+\alpha_2 S_Z(\mathbf{u}),
\qquad (22)
```

$\boldsymbol{\alpha}$ 由孔点最小二乘估计。残差 $r_i=\hat{\mu}_{\mathrm{hole}}(\mathbf{u}_i)-m_{\mathrm{KED}}(\mathbf{u}_i)$ 做三维普通克里金，球状模型的变程取 $1.15\times$ 中位孔距（本基准约 $16.5~\mathrm{m}$），垂向各向异性系数 $3$（沿孔采样密、横向稀）。实现：`geostats.regression_kriging_3d(..., residual_range=..., anisotropy_scaling_z=3)`。

孔上钉住 $\hat{\mu}_{\mathrm{hole}}$（硬数据）；孔旁 $r(\mathbf{u})$ 带上蚀变 / 风化等阻抗看不见的力学残差；离孔后残差回 0，$S_F\to m_{\mathrm{KED}}$，结构与峰值来自 $S_Z$，不再被 $\rho$ 打折。

一口井时 $\mathrm{AI}\to\mathrm{UCS}$ 的 GP 会把该孔拟合到 $\rho_{S_Z}\approx 1$，KED 的 $S_Z$ 漂移会把过拟合铺到全块。此时改用 Doyen 贝叶斯更新（`fusion.uncertainty_fusion.doyen_collocated_update`），$\rho=\mathrm{corr}(\mathrm{UCS},\mathrm{AI})$ 限制更新幅度。标准化后 [6]

```math
\lambda
=\frac{\rho\,\sigma_k^{\prime 2}}{\rho^{2}\sigma_k^{\prime 2}+1-\rho^{2}},
\qquad
y_{\mathrm{cc}}'
= y_k'+\lambda\bigl(y_s'-\rho\,y_k'\bigr).
\qquad (23)
```

孔上 $\sigma_M\to 0$ 仍钉住钻孔。

对照基线为固定权重平均

```math
S_w = w S_M + (1-w) S_Z,
\qquad w=1/2.
\qquad (24)
```

简单平均没有孔上硬数据约束，也没有把 $S_Z$ 当漂移。逆方差混合 `precision_weighted_fusion` 留作独立源基线，不再作为 $S_F$。

误差在全体素 $\lbrace t_i\rbrace$（真值）与 $\lbrace p_i\rbrace$（预测）上定义为

```math
\mathrm{RMSE}=\sqrt{\frac{1}{N}\sum_i(t_i-p_i)^{2}},
\qquad
\mathrm{MAE}=\frac{1}{N}\sum_i|t_i-p_i|,
\qquad (25)
```

```math
R^{2}=1-\frac{\sum_i(t_i-p_i)^{2}}{\sum_i(t_i-\bar{t})^{2}}.
\qquad (26)
```

实现：`validation.metrics`。体积指标限制在 $20 \times 50~\mathrm{m}$ 工作面；孔上指标只统计孔轨迹体素。

## 4. 结果

### 4.1 切片、残差与沿孔剖面

融合如何修正稀疏插值，可以从三件事分开看。横向结构与硬矿体峰值来自 $S_Z$（连续波阻抗标定），KED 不按 $\rho$ 缩峰。孔旁力学细节来自残差克里金（变程等于孔距），是硬数据而不是权重折中。风化等随深度的部分进漂移里的 $z$ 项，全块都有，不必等孔间插值。

图 3 上一行同一 UCS 色标：强度真值、钻孔插值、波阻抗插值、融合插值。下一行是预测减去真值的残差热力图（红偏高、蓝偏低，三列共用色标）：钻孔残差在硬矿体处最深；波阻抗残差轮廓对了但蚀变带估计偏高；融合残差最浅，矿体峰值不再被压矮。

![图 3. 融合优势对比](images/fusion_advantage.png)

**图 3 | 融合优势对比（含预测减去真值）。** 上排自左至右：UCS 真值、钻孔插值、波阻抗插值、融合插值，共用 UCS 色标（$\mathrm{MPa}$）。下排为残差，红为估高、蓝为估低。切片标高 $-20~\mathrm{m}$，工作面 $20 \times 50~\mathrm{m}$，$n=14$，`seed = 42`。前端出图使用同一套 $2\times 4$ 布局与中文面板名。

平面图上看着像全是波阻抗，钻孔并没有因此没用。梅花均匀布孔之后，残差克里金只在靶心一个孔距内有值，孔间回落到漂移 $m_{\mathrm{KED}}$：结构仍来自波阻抗，幅值和孔旁力学残差被钻孔拉开。钻孔另外还干一件阻抗自己做不了的事。第一，把波阻抗翻译成强度：$S_Z=g(\mathrm{AI})$ 的 GP 只能在共定位孔点上训练，没有岩心 / MWD 的 UCS，地震再连续也只是阻抗，不是爆破用的强度。第二，在孔轨迹上钉住力学真值，并在一个孔距内插值力学残差。蚀变、风化会改 UCS，却几乎不改 AI。沿孔剖面里，仅波阻抗会偏离真值，融合与 MWD 重合（图 4）。14 口孔轨迹上：仅波阻抗 RMSE $=7.23~\mathrm{MPa}$，融合 $=2.41~\mathrm{MPa}$（与仅钻孔相同）。

**图 4 | 沿孔剖面。** 两条代表性钻孔。横轴 UCS（$\mathrm{MPa}$），纵轴标高（$\mathrm{m}$）。融合在孔上钉回硬数据；波阻抗只给出趋势。黑色为真值。

## 5. 讨论与局限

表 4 把三条路径放在同一体积上：钻孔插值是最优线性估计，它在孔间光滑是因为变程外没有样品；波阻抗插值能看见矿体轮廓，是因为地震覆盖全块，但它不能看见蚀变与风化；KED 把后者写成漂移、把前者写成硬数据。这与 Xu 等 [5] 和 Doyen 等 [6] 的分工一致，只是本基准在 $n\ge 2$ 时明确选择 KED，以免 $\rho\approx 0.76$ 把峰值打到约四分之三。单井仍走 Doyen，因为此时 GP 标定会把一口井拟合到 $\rho_{S_Z}\approx 1$。

定量结论来自共定位合成矿山，而不是现场成对真值。合成模型把 $\mathrm{corr}(\mathrm{AI},\mathrm{UCS})$ 固定在约 $0.76$，并显式加入波阻抗看不见的力学残差；若现场相关更弱，KED 的漂移项会变小，融合相对仅钻孔的收益会下降。二阶平稳与线性漂移都是工作假设。球状变程被钉在 $1.15\times$ 中位孔距，因为小块上自动拟合会把变程拉到域对角线。几何各向异性系数 $3$ 是固定选择。完整的交叉变差函数协克里金未实现 [7], [9]。Tikhonov 反演的低频背景在合成实验里用真值的重平滑代替。网格 $25\times 40\times 40$ 为克里金代价所选。可视化窗口是显示截取，不是重新插值。

这些限度不改变方法结构：井是硬数据，地震是约束；融合不是两张图的加权。更细的变差函数推导与方程编号见 [插值方法.md](插值方法.md)。
